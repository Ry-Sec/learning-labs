# Learning Labs — Réseaux (TSSR) & Cybersécurité (SOC L1)

Bienvenue sur mon dépôt de travaux pratiques et de documentation technique. Ce portfolio regroupe mes exercices sur **Cisco Packet Tracer** à partir de la formation Networking Basics de Cisco, mes configurations systèmes/réseaux ainsi que mes premières investigations **SOC Niveau 1** (TryHackMe).

## Objectifs de ce dépôt

* **Maintenir une pratique régulière.**
